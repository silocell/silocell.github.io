How it's made

Plain HTML, CSS and JavaScript — no framework. Supabase for accounts, data and server functions. GitHub Pages for hosting. The server side isn't in any of these repositories: not because hiding code makes anything safe, but because those files hold keys, and keys belong somewhere private.

There's a second copy of the whole site, the lab, where things get tried before they reach anyone's homework.

Using this code

The games are open. Gate Run, the Scratch games and the learning games are released under the GNU GPL v3. Copy them, change them, put them on your own site — as long as what you share stays open too.

Homework Launchpad isn't. It's all rights reserved. You're welcome to read the code and learn from it; please don't host your own copy of it or hand it in as your own work. If you'd like to use part of it for something, ask me — the answer is very likely yes.
