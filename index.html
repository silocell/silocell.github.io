Homework Launchpad

Launch Site →

A central homework dashboard built for Year 7 pupils to keep track of evening assignments, revision tools, and peer communication in one place—eliminating the need for six open tabs and a physical planner left in a locker.

Core Features

  • Private To-Do List: Completely private to each individual user.
  • Year Chat & Private Rooms: Moderated communication spaces for students.
  • Noticeboard: Shared homework questions and school updates.
  • AI Explainer: Powered explanation tool built to clarify tough topics (capped at 10 requests daily).
  • Look-Up Tools: Native English and Simple English Wikipedia integrations.

Security Implementation

  • Row Level Security (RLS): Granular rules enforced at the database layer.
  • Server-Side Verification: State and permissions managed dynamically via backend functions.
  • Column-Level Protection: Restricts sensitive database columns from client-side retrieval.
  • Race-Condition Triggers: Atomic token spending to prevent multi-request bypasses.
